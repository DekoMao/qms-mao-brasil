## Formato e reprodução

A cópia WebM foi convertida com VP9 e Opus e comprimida abaixo de 1 MB para respeitar o limite da sincronização gerenciada. **Não é apenas uma troca de extensão:** houve conversão real dos codecs. O MP4 original Full HD permanece preservado, sem alterações.

| Propriedade | Cópia versionada WebM | Original MP4 |
| --- | --- | --- |
| Duração | Aproximadamente 75 segundos | 75 segundos |
| Resolução | 1280 × 720, 16:9 | 1920 × 1080, 16:9 |
| Taxa de quadros | 8 fps, versão compacta | 30 fps |
| Vídeo | VP9 | H.264 |
| Áudio | Opus mono, 48 kHz | AAC-LC estéreo, 44,1 kHz |
| Tamanho | 928.311 bytes | 13.491.877 bytes |
| Legendas | Incorporadas; [SRT separado](legendas-pt-BR.srt) | Incorporadas |
| Localização | Binário dentro do Git | Hospedagem externa |

Ative o som no player. Se o GitHub mostrar apenas o botão de download, abra o link de reprodução acima ou baixe o arquivo e use Chrome, Firefox ou VLC. A compactação reduz a fluidez e a qualidade da imagem em relação ao original; o conteúdo, a voz e os tempos das legendas foram preservados.
